Simulate loading states and rescues

The four panels below start on the published baselines — Hypo, Normal and Hyper chronic loading. Clamp nodes in the Node Tray to drive the network somewhere else (raise HL to degenerate it, then add SOX9 = 1 and FAK-E = 0 to attempt a rescue) and run again. Each run is added to the panels as its own series, so baseline, degenerated and rescued states sit side by side per node.
